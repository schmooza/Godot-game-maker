# The Post-it Note Game Engine — Student Editing Reliability Build

Open `project.godot` with Godot 4.3+ and press F5. Choose **Edit Adventure (Student)**.

This version focuses on reliable student editing, image replacement, saving, and Play / Test. The original escape room remains available. It is not the finished multi-board Post-it engine.

See `docs/RELIABILITY_TESTS.md` for the test checklist.


## Shared editor object interactions
See `docs/OBJECT_INTERACTIONS.md`. Adventure objects now support inspect, image swap, reveal, collect and unlock without animation.
