# HP display and victory image

In Play Mode, a small **Hit Points** counter is displayed in the top-right corner of the room image. The existing health/damage/death/restart rules are unchanged.

To customise the win screen, choose **Edit Scene → Import winning image**, then select a PNG, JPG, or WebP file. Click Save and Play / Test. When the Door is successfully unlocked, the room is replaced by this image; the dialogue panel and inventory remain visible. If no winning image has been imported, a large YOU WIN! label appears instead.

The win image is stored in the same user data location as other imported images for the current game mode.
