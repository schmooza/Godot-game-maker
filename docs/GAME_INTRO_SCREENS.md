GAME INTRO SCREENS
Each game has an optional editable introductory screen, shown when Play / Test is pressed. Students edit title and description and can import a PNG/JPG/WEBP picture from the GAME INTRO SCREEN sidebar section. Preview Intro opens it without starting gameplay. Start Game begins the existing gameplay, Back to Editor closes the overlay. Intro data is saved separately in user://intro_<game>.json and user://intro_<game>.<extension>, and is included by the project export/import feature. Existing game code, saves, audio, and gameplay logic remain unchanged.
\nIntro can be disabled per game using Enable intro screen; Play/Test then goes directly to gameplay. Preview Intro always shows the intro for editing. Each intro supports an optional WAV/MP3/OGG soundtrack, built-in Beep/Bop, preview, volume, looping and removal. Sound starts when the intro appears and stops on Start Game or Back to Editor. Audio and settings are included in the existing user:// project ZIP transfer.\n
