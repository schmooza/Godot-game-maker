# Edit Mode sections

The left editor panel groups controls with coloured headings:

- Scene & Game Settings (blue): room instructions, background and winning image import, starting HP and game help.
- Items & Interactions (amber): object selection, object image import, interaction rules, dialogue messages, passwords, damage, and position/size.
- UI & Appearance (green): dialogue/inventory colours and font sizes, scene tint, and appearance reset.

This update reorganises existing controls; gameplay and saved scene format remain unchanged.
