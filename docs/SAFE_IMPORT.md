IMPORTANT: Adventure, Racing and Bullet Hell are separate editors. The legacy shared Boss mode was removed from Adventure's mode selector, which could otherwise show placeholder graphics and incorrect controls.

Import now offers All Games, Adventure, Racing, or Bullet Hell. It makes a backup of any replaced files in the local Godot user data directory as postit_import_backup.zip, and requires a restart to reload. Import does not overwrite engine scripts or scenes.

Caution: Adventure-only restore imports shared_scenes.json, which includes shared metadata for the legacy racing and boss modes. The dedicated racing and boss settings remain in their separate files.
