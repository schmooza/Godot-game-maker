HOME SCREEN
Three square post-it note buttons in a 3-column grid. Click to open Adventure, Racing or Bullet Hell. Reset Scene was removed from the Adventure toolbar.

EXPORT / IMPORT
Export Project creates a ZIP of the local Godot user:// data, including scene JSON, tracks, sprites, imported sounds, tooltips, and scores. It does not package the engine source code. Use the same portable Godot project on the destination PC, import ZIP, then restart F5.
Import Project verifies the manifest and asks before overwriting existing local saved files. Export a backup first. The data is reloaded after restarting the engine.
