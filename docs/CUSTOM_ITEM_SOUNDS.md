Advanced item sounds (Adventure): select an item in the editor, then use ADVANCED: CUSTOM ITEM SOUND at the bottom of the sidebar. Assign Beep/Bop or import WAV/MP3/OGG, preview, remove. This plays when the item is clicked, in addition to ordinary event sounds. The path is stored in the item's existing flexible dictionary as custom_sound, so existing items remain compatible. Imported audio is copied to user:// and must be transferred separately to other school PCs. No other game modes were changed.
