Adventure hit points: In Edit Scene set Starting HP (default 3). Select an object and set Damage on click (0 is harmless). In Play Mode HP is displayed in the inventory bar. Clicking damaging objects reduces HP; at 0 the game shows GAME OVER, waits two seconds and restarts the room, restoring HP and resetting inventory. Password success without a target no longer wins the game. Save the scene to retain HP and damage settings.
