# Basic clickable images

Both **Play Adventure (Phase 2)** and **Edit Adventure (Student) → Play / Test** display clickable object pictures.

To replace pictures: choose **Edit Adventure (Student)**, select the image slot (background, desk, drawer, painting, door, or key), import PNG/JPG/WebP, and use Play / Test.

The original puzzle and code editor are preserved. Each Windows user has their own imported images.
