# Password interaction (Adventure)

Select an object in Edit Scene and choose **Password** under On click.

Set **Password** to the required word or PIN. Set **Incorrect password message** to the feedback on failure. Set **Message** to the text shown after success.

Set **Target object ID** to the ID of a hidden object to reveal it after the correct password. Leave Target object ID empty to finish/unlock the room instead.

In Play / Test, clicking the password object opens a password field and Submit button in the left dialogue panel. Press Enter or click Submit. Wrong entries do not change the puzzle. The password remains editable only in Edit Mode.
