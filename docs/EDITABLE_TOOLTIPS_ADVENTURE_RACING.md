EDITABLE TOOLTIPS
Adventure and Racing now have an Edit Tooltips switch in their top toolbars.
Switch on, RIGHT-CLICK a menu control to edit its tooltip, then save or reset.
Switch off with Done Editing Tooltips. Hover to view tooltips.
Tooltips persist separately as user://adventure_tooltips.json and user://racing_tooltips.json.
The existing Boss editor retains its own tooltip system.
