BULLET HELL EDITOR
WASD moves, SPACE fires. Each wave can import a black/white PNG; black pixels form bullet spawn positions relative to the boss centre. Angle controls the common bullet travel direction. Each wave has its own speed, lifetime, fade, duration, spawn offset, interval and boss movement velocity. Waves run in sequence and repeat.
Four PNG health states (full, half, near, dead) can be imported for each of the boss and player. Sprites change with HP; dead sprites stay visible when a fight ends. Player and boss health bars remain visible.
Power-ups spawn automatically and include Health, Shield, Rapid Fire, Damage Boost and Speed Boost. Optional PNG artwork is supported.
Victory and defeat messages are editable. Boss victory and player defeat freeze combat until Restart.
